# Papis

Papis is a powerful, highly extensible [[glossary/cli|CLI]] document and bibliography manager aimed at academic workflows.
It stores each entry's bibliographic data in a human-readable `.yaml` file, supports metadata fetching by DOI, and offers import/export to BibTeX and other formats.
It includes a [[glossary/tui|TUI]] picker, editor plugins for [[neovim|(Neo)vim]] and Emacs, a local web app (`papis serve`), and a [[python|Python]] [[glossary/api|API]] for custom scripts.
