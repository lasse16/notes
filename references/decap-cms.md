# Decap CMS

Decap CMS is a Git-based headless CMS for static sites.
It runs as a single-page app at `/admin` on your site, presenting a clean editing UI.
When editors create or update content, changes are written back to the repository as Git commits.
The content model is defined with a YAML config file.
