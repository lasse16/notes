# GraphQL

A query language for [[api|APIs]] and a runtime for executing those queries.

Unlike [[http|REST]], GraphQL lets clients request exactly the fields they need in a single request, avoiding both over-fetching and under-fetching.
Developed by Meta and open-sourced in 2015, it is widely used in modern web APIs.
